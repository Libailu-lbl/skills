# 台账 Excel 导入 / 导出

> 适用模块：**特种设备人员台账**、**特种作业人员台账**
> 版本：2026-10-27 起，特种设备台账的**数据来源改为导入**，不再内置 78 人名单

---

## 一、设计取向

| 决策 | 原因 |
|---|---|
| **台账以导入的 Excel 为准**，不预置示例名单 | 真实台账每月都在变（换证、离职、新办），内置数据只会误导；空台账 + 导入更接近实际用法 |
| **浏览器端零依赖读 xlsx** | 项目铁律是单文件 / 无外链 / 断网可用，不能引 SheetJS。用原生 `DecompressionStream` 解压 + `DOMParser` 解析，约 300 行 |
| **两个台账共用一套导入器** | 差异只在字段定义（`XIO.fields`），流程、校验、写入完全一致，改一处两个模块同时生效 |
| **导入不改动台账的增删改查** | 导入只是"批量新增"，写入后仍走原来的 store / metrics / 表格渲染，逻辑不分叉 |

---

## 二、支持的文件格式

| 格式 | 支持 | 说明 |
|---|---|---|
| `.xlsx` / `.xlsm` | ✅ | 读**第一个工作表**；表头行在前 8 行内自动识别（上面有标题行也能认） |
| `.csv` | ✅ | UTF-8（自动去 BOM），逗号分隔，支持引号包裹与 `""` 转义 |
| `.xls` | ❌ | 2003 二进制格式，提示"请另存为 .xlsx 或 .csv" |
| 多工作表 | 只读第一个 | 要导第二张表，先另存成单独文件 |

> 浏览器不支持 `DecompressionStream`（很老的版本）时会提示：**改用 CSV 导入**。CSV 走纯字符串解析，任何环境都能跑。

### 3.2 特种作业人员台账

| 列名 | 必填 | 类型 | 可识别的别名 | 说明 |
|---|:--:|---|---|---|
| 编号 | | 文本 | 人员编号 | 留空自动顺延 `TZZY-001` |
| 姓名 | ★ | 文本 | 人员姓名 | |
| 所属部门 | ★ | 文本 | 部门 | |
| 作业类别 | ★ | 枚举 | 类别、作业类型 | 必须是字典里的 11 类之一（见下） |
| 操作项目 | ★ | 文本 | 项目、准操项目 | 如「低压电工作业」 |
| 证书编号 | ★ | 文本 | 证书号、证件编号 | **导入时的判重字段** |
| 发证机关 | | 文本 | 发证单位 | |
| 有效期起 | ★ | 日期 | 发证日期、开始日期 | |
| 有效期止 | ★ | 日期 | 有效期至、到期日 | |
| 复审日期 | ★ | 日期 | 复审时间 | |
| 资质状态 | | 枚举 | 状态 | 同上；留空按有效期止推 |

**作业类别可选项**：电工作业 / 焊接与热切割作业 / 高处作业 / 吊装作业 / 制冷与空调作业 / 金属非金属矿山作业 / 石油天然气作业 / 冶金（有色）生产安全作业 / 危险化学品安全作业 / 烟花爆竹安全作业 / 其他

### 3.3 日期怎么写都行

导入时统一归一成 `YYYY-MM-DD`：

| 你写的 | 识别为 |
|---|---|
| `2026-10-27` | 2026-10-27 |
| `2026/10/27`、`2026.10.27` | 2026-10-27 |
| `2026年10月27日` | 2026-10-27 |
| `2026-1-5` | 2026-01-05（补零） |
| Excel 日期格式（存成序列号如 `46173`） | 自动换算 |
| **只有年月** `2026-12`、`2026年12月` | **该月最后一天** 2026-12-31 |
| 其他（`下个月`、`13 月`） | 判为无效，该行报错 |

### 3.4 列的顺序、多余列

- **列顺序无所谓**，按列名匹配。
- **多余列会被忽略**（如你在表里加了"序号""备注2"）。
- 列名允许带空格、全角空格、`*`、`（）`，会先归一化再比对。

## 四、数据校验规则（逐行）

按顺序执行，任一环节失败即记为该行错误：

1. **表头识别**：前 8 行里找命中列名最多的一行（≥2 个才算），所以上方有"XX公司XX台账"大标题也不影响。
2. **必需列存在性**：缺哪几列直接报出来，整批不导入。
3. **空行跳过**：整行全空的跳过，不计入错误。
4. **必填校验**：姓名 / 部门 / 证件编号 / 有效期至（设备）等为空 → 报错。
5. **日期校验**：无法识别 → `证书有效期至「下个月」不是有效日期`。
6. **枚举校验**：状态/作业类别不在可选项中 → 报错并列出可选项。
7. **默认值补全**：证书类型留空 → `N1`；状态留空 → 按有效期推（过期 / 90 天内待复审 / 有效）。
8. **去重**：
   - 文件内部重复（同一证件编号出现两次）→ 保留第一条，后面标为"文件内重复跳过"
   - 与现有台账重复 → **追加模式**跳过；**覆盖模式**不受影响（先清空）

## 五、异常处理

| 情况 | 系统行为 | 数据影响 |
|---|---|---|
| 文件不是 xlsx/csv（比如误选图片） | 弹窗红字提示，不写入 | 无 |
| 老版 `.xls` | 提示"请另存为 .xlsx 或 .csv" | 无 |
| 表头完全对不上 | 提示"没找到表头…可先下载模板对照" | 无 |
| 缺必需列 | 提示具体缺哪几列 | 无 |
| 某几行有错 | **其余行照常导入**，弹窗列出"第 N 行：原因"（超 8 条折叠） | 只写有效行 |
| 部分行重复 | 跳过并计数，提示"跳过重复 N 条" | 只写新行 |
| 浏览器不支持解压 | 提示改用 CSV | 无 |
| 覆盖模式 | 弹窗内选择"覆盖全部（先清空现有台账）"，导入前建议先导出备份 | **清空后写入** |
| 导入后 | toast 汇总"已导入 N 条，跳过重复 M 条，台账现有 K 条"，页面自动刷新 | |

> 全程**不做部分提交**：解析与校验在内存里完成，用户点「开始导入」才落盘；中途关掉弹窗什么都不会变。

## 六、导入方式

| 模式 | 行为 | 适用 |
|---|---|---|
| **追加**（默认） | 保留现有记录，新记录并入；判重字段已存在的跳过 | 每月增量补录、补新办证人员 |
| **覆盖全部** | 先清空该台账，再写入文件全部有效行 | 拿到完整最新名册时整体替换 |

## 七、台账的增删改查与展示：改了什么、没改什么

### 没有改的（保持原样）

- **新增 / 编辑 / 删除**：仍是表单弹窗 + `SD.api.createDevicePersonnel / update / remove`，字段与校验完全不变。
- **列表渲染**：表格列、搜索（姓名/工号/编号/部门/岗位）、状态 chips 筛选、按列排序、行内「操作 ▾」菜单、点姓名看证书照片，全部沿用。
- **编号规则**：仍由 `CONFIG.codeRules` 统一管（`TZSB-` / `TZZY-`，3 位序号），导入时留空也会走同一套规则顺延。

### 改了的

| 项 | 改动 |
|---|---|
| **数据来源** | 特种设备台账不再从 `deviceSeed.js` 派生，`buildDevicePersonnel()` 返回 `[]`，两版都从空台账起步（`deviceSeed.js` 已删除） |
| **工具栏** | 特种设备台账：移除「载入内置名单」，新增「导入 Excel」「导出 Excel」；特种作业台账：同样新增两个按钮 |
| **空态文案** | "还没有特种设备人员台账" → "点上方「导入 Excel」把现有名单批量导进来（可先下载模板）…"，主按钮变成「导入 Excel」 |
| **状态判定** | 设备人员：`metrics.enrichDevicePerson()` 仍按 `validTo` **实时重算**（导入时写什么状态都会被纠正，只有「停用」保留）；特种作业人员：用导入的状态值，留空时导入阶段按有效期推一次 |
| **指标卡 / chips** | 数字从数据实时算，导入后自动跟随，无需改代码 |
| **报表「人员资质预警」** | 自动多出"特种设备"来源的行（原来靠内置名单，现在靠导入数据）；台账为空时该来源自然为空 |
| **mock 数据** | 示例版 `devicePersonnel` 从 78 条变 0 条，相关测试改为"测试自己造数据 + 走真实导入链路" |

## 八、导出

- 列顺序 = 字段定义顺序，表头为中文列名；
- 状态类字段导出**中文名**（有效 / 待复审 / 已过期 / 停用），不是 `valid` 这类内部值；
- 文件名：`特种设备人员台账-20261027.xlsx` / `特种作业人员台账-20261027.xlsx`；
- 导出**全量**（不受当前筛选/搜索影响），空台账会提示"没有可导出的数据"；
- 导出件是标准 .xlsx（A4 横向、缩放到一页宽，方便打印），**能被本工具重新导入**（自洽性有测试覆盖）。

## 九、导入模板

弹窗里的「下载模板」会生成 `特种设备人员台账-导入模板.xlsx`：

- 第 1 行：中文表头（加粗、灰底）
- 第 2 行：一行灰色示例（日期填当天、枚举填第一个可选项）
- **示例行请删掉再填**，否则会被当成一条真实数据导入

## 十一、已知边界

- 只读第一个工作表；合并单元格取左上角值。
- 公式单元格读**缓存值**（Excel 保存过就有；从没打开过的文件可能为空）。
- 图片、批注、单元格底色一律不导。
- 单次导入没有条数上限（几万行也可以），但预览只列前 5 行、错误只列前 8 条。
