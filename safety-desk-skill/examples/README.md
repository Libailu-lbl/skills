# 完整示例

两套**可以直接跑**的完整工作台。代码同架构，差异只在「有没有示例数据」。

| | `safety-desk/` | `safety-desk-blank/` |
|---|---|---|
| 首屏 | 预置示例（隐患 8 / 巡检 9 / 培训 5 / 通知 / 特种作业 / 交接班…） | 全空，从第一条开始录 |
| 数据源 | 模拟数据，可切「真实接口」 | 固定本机存储 |
| 模块 | 9 个 | 同 |
| 自检 | **1355 项** | **697 项** |

## 跑起来

```bash
# 在仓库根目录
node tests/serve.js 8124 examples/safety-desk
node tests/serve.js 8125 examples/safety-desk-blank
```

也可以直接双击 `index.html`（`file://` 可用）。

**初始是受限模式**：点右上角「🔒 受限模式」输入 `123456` 解锁为安全员。
清空数据的专用密码是 `888888`。两者都建议首次使用就改掉。

## 值得看的几处

1. **导航结构**：常用（安全概览/待办/隐患/巡检/培训/特种作业▸）+ 更多（看板/通知 + 报表小组）
2. **特种作业**：父级落地页 = 4 张指标卡 + 3 张入口卡，与 3 个子级一一对应
3. **隐患流转**：状态机 + 流转留痕 + 整改通知书打印（`.docx`）
4. **交接班记录**（报表 → 安全巡检交接班记录）：
   - 19 行检查项、检查情况下拉、备注逐条编号
   - 「打印」= A4 横向 1 页，导航/按钮全部隐藏
   - 「导出 Excel」= 真 `.xlsx`，与打印件同版式
5. **照片**：不压缩原图 → IndexedDB 外置；下载时 canvas 加两行水印
6. **权限**：受限态点任何写操作都会被拦并提示输密码

## 关于示例数据（重要）

- 名单里的 **姓名 / 工号 / 身份证号 / 手机号全部是生成的假数据**（78 条，字段结构与有效期日期保持原样）
- 操作人统一为「王安全」
- 公司标识已替换为**占位图**（`assets/img/logo.png` 与 `brandLogo.js` 的 base64 是同一张）
- 换成你自己的：替换 png + 同步 base64（见 `docs/customize.md`「换品牌」）
