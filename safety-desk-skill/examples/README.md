# 可运行示例

`examples/safety-desk-blank/` —— 一套**可直接跑、也可直接拿去用**的完整工作台：
**10 个模块、52 个 JS**，零外部依赖、断网可用。

首屏是空的，从「登记第一条隐患」开始；**不带任何业务数据**——数据自己录，或从 Excel 批量导入。

> **2026-11-05 起只保留这一套**：原 `examples/safety-desk`（带示例数据、用于演示效果的版本）已移除。
> 两套代码完全相同、只差初始数据，并行维护极易不同步（每次改逻辑要同步两遍、两套各跑一遍自检）。
> 想看效果，跑起来后录几条，或导入自己的台账 Excel。

## 跑起来

```bash
# 在仓库根目录
node tests/serve.js 8124 examples/safety-desk-blank
# 浏览器打开 http://127.0.0.1:8124/index.html
```

也可以直接双击 `examples/safety-desk-blank/index.html`（`file://` 也能跑）。

**初始是受限模式**：点右上角「🔒 受限模式」输入 `123456` 解锁为安全员。
清空数据的专用密码是 `888888`。两者都建议首次使用就改掉。

## 自检

```bash
bash scripts/run_all_tests.sh        # 15 套 / 1000 项，全绿
```

## 值得看的几处

1. **导航结构**：常用（安全概览 / 待办 / 隐患 / 巡检 / 培训 / 特种作业▸）+ 报表▸（日报 / 周报 / 交接班 / 考核单）+ 更多▸（看板 / 通知）
   —— 三个下拉并列同一层，「报表」排在「更多」之前
2. **特种作业**：父级落地页 = 指标卡 + 入口卡，与 3 个子级一一对应
3. **隐患流转**：状态机 + 流转留痕 + 整改通知书打印（`.docx`）
4. **交接班记录**（报表 → 安全巡检交接班记录）：
   - 19 行检查项、检查情况下拉、备注逐条编号，备注可从《每日安全记录》Excel 导入
   - 列表按月查看（默认当月，可切月 / 回到本月）
   - 「打印」= A4 横向 1 页，导航/按钮全部隐藏
   - 「导出 Excel」= 真 `.xlsx`，白班 + 夜班各一个 sheet（各自一页，可双面打印）
5. **按年查看**：隐患 / 巡检 / 培训 / 通知 / 违章考核单共用 `components/yearBar.js`，
   默认只看当年，带年份下拉与「回到今年」
6. **照片**：不压缩原图 → IndexedDB 外置；下载时 canvas 加两行水印
7. **权限**：受限态点任何写操作都会被拦并提示输密码

## 关于数据与脱敏

- 示例里出现的 **姓名 / 工号 / 身份证号 / 手机号全部是生成的假数据**，操作人统一为「王安全」
- 公司标识已替换为**占位图**（`assets/img/logo.png` 与 `brandLogo.js` 的 base64 是同一张）
- 换成你自己的：替换 png + 同步 base64（见 `docs/customize.md`「换品牌」）
- 仓库**不含任何真实台账**（隐患、违章、培训名单、每日安全记录等都没有）
