## v1.2.6 — 「报表」改为默认收起，进报表页才自动展开

**主题**：三个下拉的默认状态统一。上一版「报表」默认摊开四个入口，侧栏首屏偏长；
现在它跟「特种作业」「更多」一样默认收起，只在进到自己的页面时自动展开。

### 变更
- `router.js` 的 `dropNode`：`auto = has`（去掉 `|| desc.key === 'reports'`）。
  即**三个下拉一律默认收起**，只有「当前页就在这个下拉里」时才自动展开。
- 进日报 / 周报 / 交接班记录 / 违章考核单 → 「报表」自动展开；进特种作业三页 → 「特种作业」自动展开；
  离开这些页面回到概览等 → 回到默认收起。
- 概览页仍可手动点开「报表」，同页重绘（点筛选等）保留手动开合状态。

### 自检
- `smoke_nav` 63 → **68 项**：概览页三个下拉全收起、报表箭头为原始态、
  进入交接班时报表自动展开且「更多」仍收起、离开后回到收起、概览页可手动点开；
  互斥用例改为「先展开报表再展开更多」以覆盖新的默认态
- 空白版 **1000 项**（15 套）、骨架 **19 项**，全绿

## v1.2.5 — 取消导航下拉的悬停展开，只保留点击

**主题**：悬停自动展开容易误触——鼠标沿侧栏往下划，整列菜单会被逐个弹开；鼠标移开又会自己收起，
和「点击展开」的语义也冲突。改为**只有点击才开合**。

### 变更
- `router.js` 的 `dropNode` 删除 `mouseenter` / `mouseleave` 监听，连同 `data-hover`、`data-pin` 一套状态一并移除；
  现在展开/收起的唯一入口就是点击父项（另一种进入方式是切页时按当前页自动展开所属分支）。
- 鼠标移入 / 移出**不触发任何动作**：收起状态移入不展开，展开状态移出不收起；
  也不会出现延迟展开/收起（没有残留定时器）。
- 保留不变：同级互斥（同一时间只开一个）、箭头旋转 + `aria-expanded`、`.in-tree` / `.active` 高亮、
  `Esc` 一键全收、换页自动展开所属分支、同页重绘保留手动开合、父项有落地页时点击顺带进入。
- 视觉上的 hover 背景高亮仍由 CSS `:hover` 负责，不受影响。

### 自检
- `smoke_nav` 59 → **63 项**：原「悬停展开 / 移开收起」一组改写为「悬停不触发开合」——
  收起态移入不展开（再等 400ms 仍不展开）、移出不变化、展开态移出不收起、移入保持、
  只有点击才收起，并断言 DOM 上不再有 `data-pin` / `data-hover` 痕迹
- 空白版 **995 项**（15 套）、骨架 **19 项**，全绿

## v1.2.4 — 「报表」提升为与「更多」并列的顶层下拉

**主题**：「报表」原先是「更多」里的嵌套下拉，点开要连开两层、层级也比「更多」深一级。
现在把它提出来，与「更多」并列同一层，并排在「更多」之前。

### 变更
- `router.js` 的二级渲染改为：**先出各 subGroup 的下拉（报表），再出「更多」**；
  「更多」只装不带 `subGroup` 的项（数据看板 / 通知公告），一项不剩时整块不渲染。
- 「报表」与「更多」现在是**同层并列**：同一个容器、同一套 `.nav-item.has-children` 样式与缩进，
  图标分别是 `daily` / `layers`，都带旋转箭头。
- 互斥关系随之简化：三个下拉（特种作业 / 报表 / 更多）**同处一层，任一时刻只开一个**，
  不再存在「更多 → 报表」的父子同时展开。
- 自动展开与高亮按新层级生效：进报表类页面只展开「报表」、只高亮「报表」父项，「更多」保持收起。

### 兼容
- 路由表、`subGroup` 标记、页面内容、权限、底部 Tab 均不变；只是渲染位置从「更多」内部移到它旁边。
- 「更多」只剩两项时仍正常显示，不会留空壳（若将来把这些项也分组，`rest` 为空则整块不渲染）。

### 自检
- `smoke_nav` 55 → **59 项**（新增并列顺序、层级一致、不再嵌套、更多只剩两项、并列互斥等断言）
- `smoke_blank` 136 → **137 项**（导航断言改为「报表与更多并列且在前」）
- 空白版 **991 项**（15 套）、骨架 **19 项**，全绿

## v1.2.3 — 导航三处下拉统一 + 常用功能按使用频率排序

**主题**：左侧导航原来三种折叠形态并存（特种作业常驻展开、更多整组折叠、报表是小标题），
规则不统一、用户要记三套；「常用功能」顺序也写死。这次把三处收拢成同一套下拉，并让常用功能按实际使用频率自动排序。

### 新增
- `assets/js/usage.js` — 功能使用频率：`bump / count / last / rank / reset / stats`，
  数据存本机 `localStorage.sd_usage_v1`（`{v,counts,last}`），写不进去时退化为内存计数。
- `tests/smoke_nav.js`（**55 项**）：下拉结构、点击/悬停、互斥、箭头与 aria、子树高亮、
  换页自动展开、同页保留手动状态、Esc 收起；常用功能按次数重排、落本机、同页刷新不重复计、reset 复原。

### 变更
- **「特种作业」「更多」「报表」统一为下拉**：
  - 点击展开/收起（点开的会「钉住」，鼠标移开不自动收）
  - 桌面悬停即展开、移开 260ms 自动收起（`matchMedia('(hover: none)')` 的触屏设备不绑悬停）
  - **同级互斥**：同一时间只允许一个并列下拉展开；父子层级（更多 → 报表）可同时展开
  - 父项箭头随展开旋转 180°，`aria-expanded` / `aria-controls` 同步；`Esc` 收起全部
  - 当前页所在分支自动展开，父项 `.in-tree` 高亮，父项本身就是页面时（特种作业）显示 `.active`
  - 换页重置手动开合、同页重绘保留（不会「点一下筛选就把菜单收回」）
  - 原 `nav-more-btn` 样式与 `nav-sub-title` 小标题下线，改用 `.nav-drop` + `.nav-item.has-children`
- **常用功能按使用频率排序**：进入功能 +1（key 与路由 id 对齐，非页面动作 `act:export` 单独记），
  只在真正切页时计、同页刷新不重复计；侧栏每次重绘按「次数降序 → 最近使用 → 内置顺序」重排；
  按钮 `title` 显示「本机用过 N 次」，标题旁小问号点一下说明排序依据。
- `listItem.quick()` 支持 `title`。
- `smoke_blank` / `smoke_shift` 里针对旧结构（`.nav-sub-title`、`data-route="special"` 在 `.nav-children` 之外）的断言改为新结构。

### 兼容
- 路由表、权限门禁、底部 Tab、计数徽标、页面内容均不变；手机（<768）仍走底部 Tab。
- 老用户本机没有 `sd_usage_v1` 时，常用功能保持原有顺序，不会首屏乱跳。

### 自检
- 空白版 **986 项**（15 套）、骨架 **19 项**，全绿

## v1.2.2 — 考核单新增「考核情况」多选字段

**主题**：现场违章的处置方式要能勾选记录（处罚 / 保证书 / 其它），「其它」还要能写清楚。
