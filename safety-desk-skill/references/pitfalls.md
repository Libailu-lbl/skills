# 踩坑记录（22 条，全是真踩过的）

> 按「症状 → 原因 → 解法」写。**遇到怪问题先在这里搜一遍**，大概率已经踩过。

---

### 1. 打印出来一片空白（屏幕预览却正常）
**原因**：`print-only.css` 里 `body > *:not(.pn-overlay):not(.pp-overlay){display:none}` 把新加的出件遮罩（如 `.sl-overlay`）也隐藏了。
**解法**：把遮罩类名加进保留名单；顺带隐藏它的工具条与提示条。

### 2. 预览一页，真打印两页
**原因**：缩放用了 `transform: scale()` —— 只改画面不改布局，分页仍按原尺寸算。
**解法**：改用 `zoom`。判支持性必须用 `getBoundingClientRect()`（`scrollHeight` 不随 zoom 变）。

### 3. 表格表头跑到标题上面去了
**原因**：浏览器**总是把 `<thead>` 渲染在表格顶部**，与源码顺序无关。
**解法**：把「标识 + 标题 + 抬头 + 表头」一起放进 `<thead>`（副作用正好是每页重复表头）。

### 4. 行高设了没反应
**原因**：`tr { height }` 只是最小值，真正决定高度是「行盒 + 上下内边距」。
**解法**：同时压 `padding`（1.4mm → 0.5mm），并显式给 `table { line-height:1.3 }`（别继承全局 1.55）。

### 5. Excel 里「班次」「日期」不见了
**原因**：`mergeAcross:2` 把 A:C 合并，后面两格按顺序落到 B、C，正好被吞掉。
**解法**：给被吞的格子显式 `col` 指定位（或补 `{v:'', border:true}` 占位）。

### 6. 导出件整体右移一格 / 内容错位
**原因**：列位递进写成了 `var c = 0; c++`（第一格落到第 1 列）。
**解法**：`var c = -1; c++`，让第一个格子落到 0 列。

### 7. 导出的 xlsx 第一格（标题）没样式
**原因**：样式索引从 0 开始，写出时 `s="0"` 被省略 → 恰好是第一个样式的那格丢样式。
**解法**：0 号留给默认样式，实际样式从 1 号起。

### 8. Excel 打开提示「工作表损坏」
**原因**（三种都遇到过）：`pane state="visible"` 是非法值；图片的 rels / Content_Types 缺一个；`<drawing>` 没挂到 worksheet。
**解法**：`pane` 整个去掉（本项目不冻结）；图片六个部件凑齐；`[Content_Types]` 登记 png + drawing。

### 9. 搜索框打不出连续文字
**原因**：每次 `input` 都整页 `refreshAll()`，输入框被重建，焦点丢失。
**解法**：只重绘列表容器（`listBox`），输入框不重建；顺带给 `data-keep-focus` 的控件还原焦点。

### 10. 页面白屏 + 控制台 `Maximum call stack`
**原因**：两个渲染函数互相调用（日历渲染 → 当天列表渲染 → 日历渲染）。
**解法**：渲染函数之间**禁止互调**，一律走 `app.refreshAll()` 统一调度。

### 11. 两个工作台数据串了
**原因**：同域名下多个页面共用 localStorage，`storageKey` 撞了。
**解法**：每个工作台一个独立 key（`wb_check_v1` / `wb_ledger_v1`）。

### 12. 改了默认角色，一堆老测试突然全红
**原因**：默认从「安全员」改成「受限」后，所有写操作被门禁拦下，断言自然全挂。
**解法**：所有套件在启动后加 `SD.auth.set('safety_officer'); SD.app.refreshAll();`。

### 13. 改了「清空数据」的流程，别的套件跟着崩
**原因**：老套件靠「点清空 → 点确认 → 数据为空」验证；流程改成密码框后，确认没点成，**弹窗留在 DOM 里**，后续 `modal()` 抓到的是清空框。
**解法**：改交互流程时，全局搜一遍旧文案/旧按钮，同步所有套件。

### 14. jsdom 里量不到高度、算不出缩放
**原因**：jsdom 不做布局，`offsetHeight / scrollHeight` 恒为 0。
**解法**：尺寸、打印、分页一律用 Chrome headless 验证；逻辑断言里对它做 0 值保护（`if (!w || !h) return;`），别算出 `Infinity`。

### 15. 用 Chrome `--dump-dom` 量尺寸，`x` 变成负数
**原因**：窗口宽度小于纸张宽度，页面横向滚动了。
**解法**：`--window-size` 至少给到纸张宽度 + 100。

### 16. `%` 宽度算出来和 Excel 对不上
**原因**：Excel 列宽是「字符单位」，中文按 2 计；换算成百分比要按**列宽总和**归一，不要按像素猜。
**解法**：`COLW = [4.41, 9, 78, 5.66, 34.08]` → 百分比 = `/sum*100`，界面与出件共用同一份。

### 17. 最长的那行文字被行高切掉
**原因**：行高固定 20.5pt，但最长一条要 37 个汉字，折成两行 → 第二行被裁。
**解法**：把列加宽到「最长一条正好一行」（78 字符）；或按估算行数放宽行高（宁可高一点也不丢字）。

### 18. 预览和打印的折行位置不一样
**原因**：`@media print` 里把表格字号从 11pt 降成 10.5pt。
**解法**：两处统一字号 —— 预览看什么，打印就该是什么。

### 19. Excel 里的全角空格被吃掉
**原因**：字符串被 trim 或写成普通字符串节点。
**解法**：写成 inlineStr 并加 `xml:space="preserve"`；签名位用固定宽度（10 个全角空格 ≈ 38.8mm）。

### 20. 写 xlsx 时 `EBUSY: resource busy`
**原因**：目标文件正被 Excel/WPS/腾讯文档打开。
**解法**：换文件名，或关掉占用程序。

### 21. Python 补丁脚本 `ANCHOR MISS`
**原因**：Windows 上文件是 CRLF，脚本里写的是 LF。
**解法**：`old.replace('\n', nl)`，或读进来 `splitlines()` 按行改。

### 22. 文件里的日期看起来不对，但打开又是对的
**原因**：某些工具层会改写输出里的日期样式，**文件本身没问题**。
**解法**：核对时用拼接字符串（`'2026'+'-10'+'-25'`）去 `count()`，别信回显。

## 附：三条「先想再做」的判断

1. **要打印 → 先要基线**（原始 xlsx / Word / 纸质扫描件）。没有基线就别开始调版式，一定返工。
2. **要改公共组件 → 先跑一遍全量**。`xlsxWriter` 改一行，日报、周报、交接班全受影响。
3. **数据类改动 → 先想「老快照还能不能读」**。能读就只加字段补默认值，不能读才升 `storageKey` 版本。
